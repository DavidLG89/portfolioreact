# Tu Máquina Retro Dev — TP2

Aplicación del grupo 27 que continúa el proyecto arcade de TP1 en React. Presenta al equipo y sus perfiles, un catálogo de recursos con búsqueda y filtro, información de una API pública, el árbol de renderizado y la bitácora.

## Ejecutar localmente

Requiere Node.js y npm.

```bash
npm install
npm run dev
```

Para generar la versión de publicación: `npm run build`. El resultado queda en `dist/`.

## Uso de inteligencia artificial

Como equipo de cuatro integrantes, usamos GitHub Copilot en Visual Studio Code como herramienta de apoyo durante el desarrollo. La IA pudo ayudarnos a resolver dudas, explorar alternativas de implementación, comprender y depurar errores, y revisar propuestas para componentes, estilos y consumo de datos desde una API.

Las decisiones sobre el proyecto, la selección de las propuestas y la revisión e integración de los cambios estuvieron a cargo del equipo, la IA fue un recurso complementario.
